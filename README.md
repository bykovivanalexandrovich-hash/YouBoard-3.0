# YouBoard

Клавиатура для Android в стиле Material You. Подстраивается под цвета системы, умеет менять форму клавиш и фон, поддерживает 25 языков.

## Возможности

- **Material You**: динамические цвета из обоев и системная тема.
- **Темы**: системная, фиолетовая, зелёная, синяя, оранжевая, красная и Windows 95.
- **Material You+**: клавиши-«печеньки» и дополнительные эффекты.
- **Свой фон**: фото из галереи в качестве фона клавиатуры.
- **Форма клавиш**: ползунки размера, высоты и закругления, скруглённые верхние края.
- **25 языков**: английский встроен, остальные словари скачиваются в приложении.
- **Подсказки и шорткаты**: подсказки слов и свои сокращения, которые разворачиваются в текст.
- **Смайлы**: панель смайлов с недавними и вкладкой 🛠️ для своего набора. Набор можно вставить текстом или загрузить из `.txt` файла. Длинное нажатие на смайл добавляет его в набор или убирает.
- **Быстрые настройки**: стрелка на клавиатуре открывает панель с режимом одной руки и переходом в настройки.
- **Голосовой ввод** и **подсказки автозаполнения** прямо на клавиатуре.
- **Группы настроек**: сворачиваются, запоминают своё состояние, с анимациями.
- **Отчёт о сбоях**: если приложение вылетело, текст ошибки можно скопировать.
- **Язык приложения**: меняется отдельно от языков клавиатуры.

## Установка

1. Скачай `YouBoard.apk` из раздела **Actions** (артефакт `YouBoard`) или из **Releases**.
2. Установи APK. Если телефон просит, разреши установку из неизвестных источников.
3. Открой YouBoard и включи клавиатуру в системных настройках.
4. Выбери YouBoard текущей клавиатурой.

## Сборка

Проект собирается через GitHub Actions: достаточно запушить `MaterialYouKeyboard.zip` в корень репозитория.
Вручную: `gradle assembleDebug` в папке `MaterialYouKeyboard`.

Требования: JDK 17, Gradle 8.10.2, Android 8.0+ (для подсказок автозаполнения нужен Android 11+).

## Приватность

Клавиатура не отправляет то, что ты вводишь. Интернет нужен только для скачивания словарей языков.
